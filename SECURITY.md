# Politica de Seguranca

## Versoes suportadas

Correcoes de seguranca sao aplicadas na branch padrao do repositorio. Commits antigos,
forks e builds nao oficiais nao recebem manutencao separada.

## Relatar uma vulnerabilidade

Use **Security > Report a vulnerability** no repositorio GitHub para enviar um relato
privado. Inclua, quando possivel:

- componente e versao ou commit afetado;
- impacto observado e cenario de ataque;
- passos minimos para reproducao ou prova de conceito;
- mitigacoes conhecidas;
- uma forma segura de contato para esclarecimentos.

Se o relato privado do GitHub nao estiver disponivel, abra uma issue sem detalhes
sensiveis solicitando um canal privado aos mantenedores. Nao publique prova de conceito,
credenciais, dados de usuarios ou instrucoes de exploracao nessa issue.

Os mantenedores farao a triagem, confirmarao o escopo e coordenarao a correcao e a
divulgacao com o relator. Aguarde a publicacao de uma correcao antes de divulgar detalhes
tecnicos.
